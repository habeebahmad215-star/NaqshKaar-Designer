# NaqshKaar Designer

Professional Urdu Graphic Designer for mobile.

## Features

- Urdu text designing
- RTL text support
- Shapes and images
- Multiple design pages
- Canvas resizing
- Undo and redo
- PNG export
- JPG export
- PDF sharing
- Project data structure
- Offline project storage foundation
